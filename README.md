## Подготовка к запуску:

1. Установка зависимостей:  
   ```pip install -r requirements.txt```
2. Настройка pytest:  
   [pytest.ini](pytest.ini)
3. Запуск тестов:  
   ```pytest```
4. Просмотр allure-отчета:  
   ```allure serve reports/allure-results```
